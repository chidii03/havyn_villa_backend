# Design Principles

> Status: Draft · Phase 1 · Owner: Design/UX Director. Extends `brand/02-brand-identity.md`.

## The seven principles
1. **Photography first.** The place is the hero; UI recedes. Generous whitespace, strong hierarchy.
2. **Honest by design.** Show whole prices, real availability, true photo counts. No dark patterns, no fake urgency.
3. **Search is the product.** Discovery and search must be the fastest, clearest paths in the app.
4. **Trust in every surface.** Verification badges, transparent reviews, clear policies, calm error states.
5. **Calm motion.** Motion clarifies transitions; never decorates. Respect reduced-motion.
6. **Accessible always.** WCAG 2.2 AA is a floor, not a goal. Keyboard, contrast, focus, semantics.
7. **One system, every device.** Responsive web now, native mobile later — shared design tokens and patterns.

## Explicitly avoided (per brief)
Generic AI dashboards, excessive gradients, random glassmorphism, oversized rounded cards everywhere, unnecessary animation, template look. Every screen should feel like a premium travel company made it.

## Design method
Tokens → primitives → components → patterns → flows. Nothing hardcoded; everything traces to `design/02-design-tokens.md`.
